# DOT Digital Group - Backend IA

Desafio técnico Backend + IA: API de livros, chatbot com Langchain e busca semântica com embeddings.

## Requisitos

- Python 3.14+
- Um único `requirements.txt` cobre as três questões:

```bash
python3 -m venv .venv

.venv/bin/pip install -r requirements.txt
```

> As Questões 2 e 3 exigem uma chave da API da OpenAI (`OPENAI_API_KEY`). Veja o `.env.example` de cada questão.

## Questões

- [Questão 1 — API de Livros](docs/questao1_api_livros.md)
- [Questão 2 — Chatbot com LangChain](docs/questao2_chatbot_langchain.md)
- [Questão 3 — Busca Semântica com Vector Stores e Embeddings](docs/questao3_busca_semantica.md)
